# YouTube Global Statistics Dashboard (Power BI)

## Project Overview
This project analyzes global YouTube statistics using Power BI to explore platform growth, user demographics, content trends, and creator earnings. The dashboard provides insights into YouTube usage patterns, revenue trends, and audience distribution across the world.

---

## Dataset Description

The dataset includes multiple aspects of YouTube platform statistics such as:

• Global YouTube users and premium subscribers  
• Device usage for video views  
• Age and gender demographics  
• Top subscribed channels  
• Most viewed YouTube videos of all time  
• Estimated annual earnings of top YouTubers  
• Global advertising revenue trends  
• YouTube Shorts performance  
• Country-wise YouTube user distribution  

---

## Data Modeling

The report follows a dimensional modeling approach with separate tables for users, demographics, revenue, and content statistics. Relationships were established using appropriate keys such as year, category, and demographic attributes to ensure accurate filtering and aggregation across visuals.

---

## Key Insights

• Mobile devices account for the largest share of YouTube video views globally.

• A small number of creators generate a significant portion of total earnings on the platform.

• Music and entertainment content dominate the most viewed videos of all time.

• Advertising revenue shows fluctuations across quarters but continues to remain a major monetization source.

• Younger audiences (18–34) represent the largest demographic segment of YouTube users.

• Countries with large populations contribute the highest number of YouTube users globally.
